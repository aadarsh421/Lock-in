9–6 LOCK-IN PWA
================
This is a Progressive Web App. It works offline after the first load.

IMPORTANT:
A PWA must be served from HTTPS (or localhost) for installation/service-worker support.
The easiest tablet-only route is to upload these files to a static HTTPS host such as GitHub Pages or another static hosting service, then open the resulting HTTPS page in Chrome and choose "Add to Home screen"/"Install app".

Features:
- 9 AM–6 PM live countdown
- Streak counter stored locally
- 🚨 MAT KAR, MADARCHOD button
- Vibration on urge button (where browser/device permits)
- 10-minute reset countdown
- 6 PM completion
- Offline cache after first successful load
